# Currículo Digital — Pedro Lucas Braga Ximenes

Site de currículo/portfólio responsivo feito com HTML, CSS e JavaScript puro com Antigravity seguindo o arquivo orientação.txt. Não precisa instalar dependências nem executar servidor para visualizar localmente.

## Rodar localmente

1. Baixe ou clone este repositório.
2. Abra `index.html` no navegador.

Opcional: use a extensão **Live Server** no VS Code para abrir em `http://127.0.0.1:5500`.

## Publicar no GitHub Pages

1. Envie os arquivos deste projeto para a raiz do repositório `curriculo-pedro-lucas`.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
5. Aguarde a publicação. O endereço costuma ficar como `https://pedrolucasbragaximenes.github.io/curriculo-pedro-lucas/`.

## Antes de entregar

Confira se e-mail, links, formação, datas e descrições estão corretos. Os indicadores de habilidade são aproximados e podem ser ajustados diretamente no `index.html` e `styles.css`.
